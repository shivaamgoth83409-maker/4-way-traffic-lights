<section class="card info"><h2>How to build it with Arduino</h2><p><strong>Hardware:</strong> Arduino Uno, 12 LEDs (4 sets of red/amber/green), 12 × 220–330 Ω resistors, breadboard and jumper wires. Connect each LED anode through its resistor to a pin; connect all cathodes to GND. Suggested pin groups: North 2–4, East 5–7, South 8–10, West 11–13 (red, amber, green).</p><details><summary>View Arduino sketch</summary><pre><code>const byte lights[4][3] = {
  {2, 3, 4},    // North: red, amber, green
  {5, 6, 7},    // East
  {8, 9, 10},   // South
  {11, 12, 13}  // West
};
const byte RED = 0, AMBER = 1, GREEN = 2;
const unsigned long GREEN_MS = 15000, AMBER_MS = 3000;

void setRoad(byte road, byte color) {
  for (byte c = 0; c &lt; 3; c++)
    digitalWrite(lights[road][c], c == color ? HIGH : LOW);
}
void allRed() {
  for (byte r = 0; r &lt; 4; r++) {
    digitalWrite(lights[r][RED], HIGH);
    digitalWrite(lights[r][AMBER], LOW);
    digitalWrite(lights[r][GREEN], LOW);
  }
}
void setup() {
  for (byte r = 0; r &lt; 4; r++)
    for (byte c = 0; c &lt; 3; c++) pinMode(lights[r][c], OUTPUT);
  allRed();
}
void loop() {
  runPair(0, 2); // North + South
  runPair(1, 3); // East + West
}
void runPair(byte first, byte second) {
  allRed(); delay(1000);  // safety clearance between directions
  setRoad(first, GREEN); setRoad(second, GREEN);
  delay(GREEN_MS);
  setRoad(first, AMBER); setRoad(second, AMBER);
  delay(AMBER_MS);
  allRed(); delay(1000);
}</code></pre><p class="caution">For a classroom model only. Real road signals require certified controllers, conflict monitoring, fail-safe hardware and local traffic authority approval.</p></details></section></main>
